# Skills

Набор skills: https://github.com/mattpocock/skills

В этой папке находятся навыки для работы над проектом:

- `code-review` — проверка изменений на соответствие стандартам проекта и требованиям задачи.
- `codebase-design` — проектирование границ и интерфейсов модулей.
- `diagnosing-bugs` — диагностика ошибок, сбоев и регрессий производительности.
- `domain-modeling` — формирование и уточнение предметной модели и терминологии.
- `grill-with-docs` — критический разбор планов и дизайна с фиксацией решений в документации.
- `handoff` — подготовка краткого документа для передачи работы другому агенту.
- `php-dev` — разработка и рефакторинг PHP-кода в соответствии с правилами проекта.
- `tdd` — разработка через тестирование и интеграционные тесты.
- `tech-doc` — создание и обновление русскоязычной технической документации модулей.
- `writing-for-agents` — подготовка инструкций и документации для агентов.
