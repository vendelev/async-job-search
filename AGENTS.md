# AGENTS.md

## Язык общения

Всё общение с пользователем ведётся на русском языке.

## О проекте

`async-job-search` -- учебное CLI-приложение для периодического поиска вакансий
на HH.ru и уведомления о новых подходящих вакансиях в Telegram. 
Целевая архитектура и границы первого инкремента описаны в [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

Код приложения пока является каркасом: не представляй проект как реализованный,
если изменение не добавило соответствующую функциональность.

## Инструкции

- Перед изменением архитектуры, границ модулей используй общие правила из `.agents/prompts/project.md`
- Перед изменением поведения поиска прочитай `docs/ARCHITECTURE.md`.
- Перед изменением PHP загрузи и соблюдай `.agents/skills/php-dev/SKILL.md`.
  Навык ссылается на архитектурные правила, компромиссы, стиль и справочник возможностей PHP.
- Конфигурации и скрипты являются источником правды для среды и проверок:
  `docker/php/Dockerfile`, `compose.yaml`, `Makefile` и `backend/composer.json`.
  Не дублируй их содержимое в документации без необходимости.

## Рабочий цикл

- Команды запускай из корня репозитория через `make`.
- После изменения PHP выполняй подходящую проверку: `make php-test` для полного набора 
  или `make php-unit-tests` для PHPUnit.
- Конфиденциальные значения хранятся в `.env`; не добавляй их в код, документацию, логи или Git.
